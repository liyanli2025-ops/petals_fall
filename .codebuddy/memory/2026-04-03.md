# 2026-04-03 工作日志

## 花瓣雨 AR 全息 H5 项目

### 项目创建
- 从零搭建了花瓣雨 AR 全息 H5 项目
- 技术栈：Three.js + HTML5 Camera API + DeviceOrientation API
- 支持手机端（陀螺仪）+ PC端（鼠标）双端适配，一套代码

### 项目结构
```
flowers/
├── index.html          # 入口（引导页 + 主场景）
├── css/style.css       # 响应式样式
├── js/
│   ├── camera.js       # 摄像头管理模块
│   ├── particles.js    # 3D花瓣粒子系统
│   ├── gyroscope.js    # 陀螺仪/鼠标交互控制
│   └── app.js          # 主控制器
```

### 核心功能
1. 摄像头实时画面作为背景（无摄像头时降级为渐变背景）
2. 程序化3D花瓣（贝塞尔曲线轮廓 + 弯曲变形），DoubleSide双面渲染
3. 花瓣自由翻转 + 物理飘落（重力、风力、摇摆、螺旋）
4. 360°环绕：手机端陀螺仪/PC端鼠标控制相机视角
5. 花瓣密度可调、自动性能调节
6. 三种配色方案混合使用（樱花粉、桃花、白樱）

### 第四轮更新 - 景深光圈效果 + iOS Safari 权限修复

#### 花瓣景深光圈效果
- 花瓣整体缩小（几何体尺寸从 0.38~0.55 缩小到 0.18~0.32）
- 花瓣数量增多：手机 250 / PC 350（之前 150/250）
- 三层景深材质系统：
  - 近景（15%）：半透明（opacity 0.45）+ 粉色发光（emissive）模拟光圈散景虚化
  - 中景（55%）：清晰焦点（opacity 0.95），这是视觉焦点区域
  - 远景（30%）：轻微淡化（opacity 0.75）+ FogExp2 雾气自然衰减
- 添加 FogExp2 指数雾效果，远处花瓣自然融入背景

#### iOS Safari 摄像头/陀螺仪权限修复
- **根因**：iOS Safari 要求 `DeviceOrientationEvent.requestPermission()` 和 `getUserMedia` 必须在用户手势事件的同步调用栈内调用。之前代码在 async 函数中先 await 摄像头再请求陀螺仪，陀螺仪的 requestPermission 已脱离手势上下文
- **方案**：在 click handler 内同步创建两个 Promise（摄像头+陀螺仪权限请求），用 Promise.all 并行等待，确保两个权限请求都在用户手势调用栈内发起
- camera.js 新增 `initWithStream(stream)` 方法，接收外部已获取的媒体流
- gyroscope.js 新增 `initWithPermission(granted)` 方法，接收外部权限结果
- 支持后置摄像头失败自动降级前置摄像头

### 第五轮更新 - 三层 Canvas 真景深 + 人物遮挡 + iOS 权限深度修复

#### 架构重构：多层 Canvas
- 从单 canvas 重构为 **3 层独立 canvas**（canvas-far / canvas-mid / canvas-near），每层一个 Three.js renderer
- 近景层 CSS `filter: blur(6px)` 实现**真正的高斯模糊景深**（用户要求不是透明度而是模糊）
- 远景层 CSS `filter: blur(2px)` 轻微模糊
- 中景层清晰锐利（焦点区域）
- 添加 WebGL 上下文创建失败降级机制（手机如果 3 个上下文不可用，自动降级为单 canvas）

#### 花瓣视觉调整
- 花瓣几何体尺寸**调大**：0.28~0.50（之前 0.18~0.32 太小像脏东西）
- 花瓣数量增加：手机 300 / PC 400
- 下落速度 fallSpeed 从 1.2 提高到 **2.8**（更快、更有动感）
- 风力增强：x=0.3, z=0.2

#### 人物遮挡（人体分割）
- 新增 `segmentation.js` 模块，使用 **MediaPipe SelfieSegmentation** 实时人体分割
- 人物遮罩层（canvas-person）位于中景花瓣之上、近景花瓣之下
- 人物区域从摄像头画面中抠出，覆盖在远景+中景花瓣之上，实现花瓣被人遮挡效果
- 手机端每 2 帧处理一次分割（性能优化），PC 端每帧处理

#### iOS Safari 权限深度修复
- 添加 debug 信息显示（Landing 页底部显示权限请求过程）
- 添加 **HTTPS 协议检测**：非 HTTPS 时提示用户
- 按钮同时绑定 `click` 和 `touchend` 事件（iOS Safari 上 touchend 更可靠传递 user activation）
- 摄像头请求使用 `facingMode: { ideal: 'environment' }` 而非 `facingMode: 'environment'`（避免 OverconstrainedError）
